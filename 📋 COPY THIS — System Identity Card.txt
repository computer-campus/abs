💸 Loan Given (ঋণ বিতরণ):
- ৩টা field side by side: মূল ঋণ | অনলাইন | নগদ উত্তোলন
- মোট ঋণ = মূল ঋণ + নগদ উত্তোলন
- ক্যাশ নেয়নি = মোট ঋণ − অনলাইন − ক্যাশ
- **২টা আলাদা txn তৈরি হয়:**
  1. loan_given txn (amount = মূল ঋণ)
  2. withdrawal txn (amount = নগদ উত্তোলন, linkedFrom: 'loan_given')
- মাদার অ্যাকাউন্টে ২বার আলাদা যোগ: + মূল ঋণ, + নগদ উত্তোলন
- Detail popup layout:
  🏦 মূল ঋণ | 💵 নগদ উত্তোলন (pasha pashi)
  = মোট ঋণ (full width)
  🌐 অনলাইন | 💸 ক্যাশ | 💰 ক্যাশ নেয়নি (3 columns)

🏦 Deposit (নগদ/অনলাইনে জমা):
- ধরন dropdown: 💵 ক্যাশ / 🌐 অনলাইন
- ক্যাশ → notes grid + vault += notes + মাদার account -=
- অনলাইন → only amount field + মাদার account -= only
